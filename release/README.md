# Dawn Launcher - 重构版 (Rust + Slint)

> **v0.17 新增**
>
> - **统一的「新建项目」窗口**：取代原先一连串 PowerShell 输入框。左侧类型栏
>   包含 文件 / 文件夹 / 网址 / 系统 / 开始菜单 / Appx / 多项目，右侧按类型切换表单。
> - **系统项目**：内置常用 / 系统设置 / 管理工具 / 系统文件夹 / 快捷操作分类，
>   可搜索、点击图标即选中并自动填入名称与目标。
> - **开始菜单 / Appx 扫描并入新建项目**：点开对应类型即后台扫描，
>   网格展示图标与名称，搜索过滤后点击即可创建（不再需要「工具 → 扫描导入」）。
> - **多项目**：列出所有分类下的项目（按「分类 · 项目」显示，可跨分类勾选），
>   设置启动间隔（毫秒，可 ±100 调整），创建后按顺序依次启动。
> - 新建项目窗口支持 名称、图标、快捷键、全局快捷键、路径、起始位置、启动参数、
>   备注、以管理员身份运行。
>
> **v0.16 新增**
>
> - **分类「仅图标」模式**：分类右键「切换为仅显示图标」，该分类下只显示图标、
>   不显示名称，设置随分类保存；再点一次「显示项目名称」可恢复。
>   （仅图标时图标在卡片内垂直居中。）
>
> **v0.15 修复**
>
> - **多项目新建不再卡死**：改用真正的多行输入框（首行名称，之后每行一个路径）。
>   此前对话框以 `CREATE_NO_WINDOW` 启动且被挤成单行，看不到提示、输入后也不创建项目。
> - **对话框置顶**：所有输入 / 选择对话框去掉 `CREATE_NO_WINDOW` 与 `-NonInteractive`，
>   并设置 `TopMost`，不会再被主窗口遮住或导致界面无响应。
> - **中文输入不再乱码**：PowerShell 输出统一设 UTF-8。
> - **卡片图标与名称严格居中**：改用绝对定位计算中心点，图标不在偏左。
> - **拖拽手柄可见**：卡片左上角 / 分类右侧显示 grip 小把手，拖拽排序可正常触发
>   （此前 `TouchArea` 覆盖在手柄上层，拖拽从未生效）。
>
> **v0.14 更新**
>
> - **分类级项目设置**：分类右键可切换卡片/列表布局、设置图标大小、切换显示过滤
>   （全部 / 仅文件 / 仅文件夹），设置随分类保存并即时生效。
> - **列表布局渲染**：列表模式下项目按行显示（小图标 + 名称），占满整行宽度。
> - **多项目（kind=5）**：项目区右键「新建多项目…」，多行输入子项路径（可带 `;参数`），
>   点击后按间隔依次启动全部子项。
> - **系统项目（kind=3）**：项目区右键「新建系统项目…」，内置 20 项常用系统命令，
>   也可输入编号或 `名称:目标` 手动添加。
> - **分类 / 项目快捷键**：分类与项目右键「设置快捷键…」输入如 `Ctrl+Alt+A`，
>   保存后重启生效，任意界面下按热键可切换分类或启动项目。
> - **网络搜索**：快速搜索输入 `:g 关键词` 直接打开 Google 搜索结果
>   （另支持 `:b` Bing、`:ba` 百度、`:gh` GitHub、`:so` StackOverflow）。
> - **备注链接**：项目备注中的 `http(s)://` 链接可在右键菜单「打开备注链接」直接打开，
>   亦可「复制备注」。
>
> v0.13 更新
>
> - **分类右键菜单补全**：新增「设为默认分类」「设置图标…」「排除搜索」。
>   - 设为默认分类后，每次启动自动选中该分类；
>   - 分类支持自定义图标（选择本地图片，渲染在分类名左侧）；
>   - 排除搜索后，该分类下的项目不会出现在快速搜索结果中。
>
> v0.12 修复：启动参数 / 起始位置 / 管理员运行生效；项目右键新增「以管理员身份运行」
> 「复制名称」「移动到…」「复制到…」。
> v0.11 新增项目右键「资源管理器菜单」，直接调用系统 COM `IContextMenu` 弹出原生右键菜单
> （剪切/复制/发送到/属性等系统命令均可用）。
> 此前 v0.10 已实现项目/分类拖拽排序、聚合分类、窗口不透明度、窗口背景图、
> 边缘吸附与自动隐藏、鼠标中键显示/隐藏，并支持通过 `data/tray.ico` 自定义托盘图标。

## 技术栈

- **Rust** + **Slint 1.18** (声明式 UI，兼容 1.18 API)
- **rusqlite** (SQLite 数据库，与原项目表结构兼容)
- **windows-rs** (Win32 API 调用)
- 交叉编译: Linux → Windows (mingw-w64)

## 使用方法

### 1. 启动

直接双击 `dawn-launcher.exe` 即可运行。

数据存储在 exe 同级的 `data/` 目录下：
- `data/dawn-launcher.db` (SQLite 数据库)

### 2. 添加项目（三种方式）

**方式 A：通过文件选择对话框**
1. 点击右上角「+ 添加项目」按钮
2. 在弹出的对话框中选择文件/快捷方式
3. 项目会自动添加到当前分类，名称取自文件名，图标自动提取

**方式 B：拖拽文件 URL**
- 将文件资源管理器中的文件拖入窗口右侧区域
- ⚠️ 注意：Slint 1.5 的拖拽支持需要 winit 后端配合，当前版本可能不触发，
  如拖拽无响应，请使用方式 A

**方式 C：从原 Electron 版数据库导入**
1. 找到原版数据库（通常在 `%APPDATA%\Dawn Launcher\`）
2. 复制为 `data/dawn-launcher.db` 覆盖即可

### 3. 删除/重命名

- 项目右键 → 弹出确认框 → 确认删除
- 分类右键 → 选择「重命名」或「删除」

| 版本 | 安装包体积 | 安装后体积 |
| --- | --- | --- |
| 原 Electron 版 | ~80 MB | ~180 MB |

体积减少 **95%**，且**无任何运行时依赖** (无需 WebView2 / Node.js / .NET)。

## 已知限制

1. **图标提取**：当前使用 PowerShell 间接提取图标，速度较慢。
   首次添加大量项目时可能略有卡顿，后续将改用原生 `IShellItemImageFactory`。

2. **拖拽支持**：Slint 1.5 的窗口级拖拽事件尚未完整启用。
   当前 `item-dropped` 回调已就绪，但需要 winit 端的事件桥接才能触发。
   临时方案：使用「+ 添加项目」按钮添加。

3. **对话框**：确认框使用原生 MessageBox，输入框/动作选择框使用 PowerShell 的
   `Microsoft.VisualBasic.Interaction.InputBox`，在精简版 Windows 上可能略有延迟。

4. **UI 美观度**：已实现 11 套预设主题 + 自定义主题颜色，
   暂未实现透明窗口、窗口背景图、动画过渡等高级视觉效果。
