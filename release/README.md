# Dawn Launcher - 重构版 (Rust + Slint)

> ⚠️ **MVP 版本说明**
>
> 当前为 Rust + Slint 全面重构的**第一阶段最小可用版本**，仅用于验证技术路线与核心功能。
> 大量原 Electron 版功能尚未迁移，请在测试时关注已实现部分。

## 技术栈

- **Rust 1.92** + **Slint 1.18** (声明式 UI)
- **rusqlite** (SQLite 数据库，与原项目表结构兼容)
- **windows-rs** (Win32 API 调用)
- 交叉编译: Linux → Windows (mingw-w64)

## 使用方法

### 1. 便携版 (推荐测试)

直接双击 `dawn-launcher.exe` 即可运行。

数据存储在 exe 同级的 `data/` 目录下：
- `data/dawn-launcher.db` (SQLite 数据库)

### 2. 与原 Electron 版数据库兼容

当前数据库表结构与原项目**完全兼容**：
- `classification` 表 (分类)
- `item` 表 (项目)

如需复用原 Electron 版数据：
1. 找到原版数据库 (通常在 `%APPDATA%\Dawn Launcher\` 或便携版 `data/` 目录)
2. 复制到本程序同级 `data/dawn-launcher.db`
3. 启动本程序即可读取

> ⚠️ 注意：当前版本**只读**模式使用原数据库，不会修改原数据结构。
> 双击打开项目时会更新 `openNumber` 和 `lastOpen` 字段 (通过 `json_set`)，
> 但不会破坏其他字段。如需保护原始数据，请先备份。

### 3. 数据库为空时

程序首次启动会在 `data/` 目录自动创建空数据库并插入一个名为"常用"的默认分类。
此时项目列表为空，属正常现象 (当前版本无添加项目的 UI)。

## 已知限制

1. **图标显示**：原 Electron 版通过 `IShellItemImageFactory` 提取文件图标，
   当前 Rust 版本尚未迁移该功能，因此没有 icon 数据的项目会显示空白。
   解决方案：从原 Electron 版数据库复制已有 icon 数据即可正常显示。

2. **双击打开**：通过 `cmd /C start` 调用系统默认程序打开。
   对 .lnk 快捷方式的解析（提取 target 后打开）尚未启用，
   直接打开 .lnk 文件会由系统处理。

3. **UI 美观度**：MVP 版本 UI 较为朴素，未实现透明窗口、自定义主题、动画等。
   后续迭代会逐步还原原版的视觉体验。
